# BYTEA website

وب‌سایت چندبخشی و واکنش‌گرای BYTEA با HTML، CSS و JavaScript خالص.

## اجرا
1. فایل ZIP را استخراج کنید.
2. فایل `index.html` را با مرورگر باز کنید.

برای اجرای محلی با سرور:
```bash
python -m http.server 8000
```
سپس به `http://localhost:8000` بروید.

## انتشار
محتویات پوشه را می‌توانید روی GitHub Pages، Netlify یا هر هاست استاتیک بارگذاری کنید.

## ساختار
- `index.html` ساختار و محتوای همه بخش‌ها
- `styles.css` طراحی واکنش‌گرا و تم بصری
- `script.js` منوی موبایل و تشخیص بخش فعال
